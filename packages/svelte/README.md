# @boardloom/svelte

Planned thin Svelte host adapter around the shared DOM runtime and host contract.

Status: T01 package skeleton only. T16 implements the adapter and example. The adapter must not contain a second copy of core UI logic.

Distribution target: browser ESM with TypeScript declarations and Svelte peer dependencies fixed in T16. npm publication is not authorized at T01; the planned scoped name is used for tarball consumers only.
