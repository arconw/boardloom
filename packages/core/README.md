# @boardloom/core

Planned package for the Boardloom headless runtime, document model, query and realtime orchestration, registries and shared contracts.

Status: T01 package skeleton only. No public API is implemented. T02 and later tasks define the contracts. The package must not depend on the DOM, React, Angular, Svelte, a server, SQL, Prisma or database drivers.

Distribution target: browser ESM with TypeScript declarations. npm publication is not authorized at T01; the planned scoped name is used for tarball consumers only.
