# @boardloom/view-dom

Planned package for the Boardloom framework-neutral viewer and editor DOM runtime, accessible shell and scoped design tokens.

Status: T01 package skeleton only. The styles entry establishes the cascade layer name; T05 implements design tokens and T06 implements the DOM runtime. The package must not depend on a backend, a database or a UI framework.

Distribution target: browser ESM with TypeScript declarations and `@boardloom/view-dom/styles.css`. npm publication is not authorized at T01; the planned scoped name is used for tarball consumers only.
