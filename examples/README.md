# Boardloom examples

Runnable consumers for the built Boardloom packages. Each example must install and run the built package or tarball rather than relying only on workspace source aliases.

- `react/`: Vite React example with synthetic data, locale/timezone forwarding, host message overrides, imperative actions and Strict Mode lifecycle coverage.
- `angular/`: Angular standalone-component example with synthetic data, input/output forwarding, locale/timezone updates, host message overrides, editor/viewer switching and destroy cleanup.
- `svelte/`: Svelte 5 example with a bindable adapter handle, callback props, locale/timezone updates, host message overrides, editor/viewer switching and destroy cleanup.
