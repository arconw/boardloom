T05 · Localization and RTL

Copy expands; the layout and the data direction hold

The design tolerates long German and Russian labels, CJK line breaking and Arabic RTL without changing the host page. Numbers stay bidi-isolated, chart plots keep their data direction, and every sample is a functional design reference rather than a claim of linguistic certification.

Stable keys Each sample is annotated with the message key from message-keys.json. Host data labels are not translated by the framework.
Logical layout Spacing, borders and drawer sides use logical properties. Arabic sets dir="rtl" only on the scoped Boardloom root.
No certification claim These are functional samples. T17 records key parity, fallback, interpolation, browser coverage and linguistic limitations honestly.
