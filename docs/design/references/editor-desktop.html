T05 · Editor composition · Desktop

Authoring at the edges, the chart still at the centre

The editor adds a block library and a precise property inspector without turning the board into a settings page. A persistent draft bar makes apply and discard explicit. The selected block has a visible outline, pointer handles and an equally visible keyboard layout path.

Three regions Library, canvas and inspector are peers in the layout, but the canvas keeps the widest and most open region.
Draft clarity Dirty status, undo, redo, apply and discard are always visible. Discard asks before losing more than one change.
Keyboard parity Move and resize controls are buttons near the selection, not a pointer-only gesture. Arrow, Enter and Escape behavior is stated in the UI.
