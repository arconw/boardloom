T05 · Viewer composition · Desktop

A calm analytical surface, in both themes

The viewer leads with board identity, provenance and filter scope. Controls stay compact; the chart canvas and its data alternatives carry the visual weight. The two artboards use the same synthetic assessment fixture so light and dark parity can be compared directly.

Hierarchy Board title, provenance and mode are one compact band. Filters sit on a single strip. The canvas is not enclosed in another page-level card.
Accessibility Each chart has a visible summary and a disclosure table. Filter origin is written as a scope word. Status uses an icon or dot plus text.
Provenance Synthetic assessment fixture, deterministic values, no real schools or records. Boardloom branding is documentation chrome, never forced into an embedded host.
