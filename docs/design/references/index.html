Boardloom design references

A reviewable design basis for the framework viewer and editor: warm light surfaces, deep ink dark surfaces, a petrol accent, restrained amber emphasis and a chart palette that always has a non-color companion. Every composition on this site is a static design reference, not a live Boardloom build.
