T05 · State gallery

States are part of the visual system

Loading, empty, error, stale, partial, diagnostics, filter origin, comparison, realtime reconnect and plugin failure each have a distinct composition, message keys and announcement plan. No state fabricates values, hides scope or takes down the whole board.

Word plus shape Every state has a visible label and an icon or shape. Color supports the message but is never the only carrier.
Scope stays visible Empty, stale, partial and filter-origin states repeat the active scope or a route to it.
Recovery is explicit Retry, reset, refresh, pause, resume, disable and remove are real labeled actions.
