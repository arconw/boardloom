T05 · Editor composition · Narrow

Authoring tools arrive as drawers, not as a shrunken desktop

At narrow widths the canvas stays primary. Blocks and Inspect open from a bottom drawer, the draft actions stay reachable, and layout controls remain labeled buttons. At 320 px the inspector drawer is modal and returns focus to its trigger; at 390 px the library drawer can remain non-modal while the canvas is still available.

Drawer, not sidebar Blocks and Inspect are tabs in one drawer. The trigger, heading, close action and focus return are all explicit.
Draft remains reachable Apply and Discard stay in the draft bar when non-modal and move into the modal sheet's sticky footer when the drawer covers the canvas.
Keyboard first Move and resize use labeled arrow controls. The canvas does not require a drag gesture to be usable at 320 px.
